# MAGI Optimizer — Design Ideas

## Selected Design Philosophy: Apple WWDC / Premium Fintech Dark

**Design Movement:** Apple WWDC meets Bloomberg Terminal — deep black backgrounds, surgical typography, vibrant gradient accents, and data-forward layouts.

**Core Principles:**
1. Deep black (#000000 / #0A0A0A) backgrounds with subtle glass-morphism panels
2. Space Grotesk for display headings; Inter for body and data
3. Electric blue (#007AFF) and violet (#A855F7) gradient accents — used sparingly for emphasis
4. Data is the hero: numbers are large, bold, and gradient-colored; labels are small and muted

**Color Philosophy:**
- Background: #000000 / #0A0A0A
- Surface: rgba(255,255,255,0.03) with 1px white/10% borders
- Primary Accent: #007AFF (Apple Blue)
- Secondary Accent: #A855F7 (Violet)
- Success: #10B981 (Emerald)
- Danger: #EF4444 (Red)
- Text Primary: #FFFFFF
- Text Secondary: #A1A1AA (Zinc 400)
- Text Muted: #71717A (Zinc 500)

**Layout Paradigm:**
- Multi-step wizard flow (4 steps): Profile → Accounts → Optimize → Results
- Left sidebar for navigation/progress; right panel for content
- Results page: split view — left prescription, right live chart

**Signature Elements:**
1. Glowing gradient numbers for key metrics (MAGI, subsidy amount, savings)
2. Subtle radial gradient "orbs" in corners for ambient depth
3. Animated progress bar between wizard steps

**Typography System:**
- Display: Space Grotesk 700/800, 40-64px
- Section Titles: Space Grotesk 700, 24-32px
- Body: Inter 400/500, 14-16px
- Data Labels: Inter 600, 12px uppercase with letter-spacing
- Numbers: Space Grotesk 800, 48-80px with gradient fill
